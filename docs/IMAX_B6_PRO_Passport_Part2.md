# Паспорт проекта IMAX B6 PRO — Часть 2: Софт, интерфейс и калибровки

## 1. Модульная структура прошивки (14 файлов в папке `IMAX_B6_PRO`)
Проект организован в виде 14 раздельных файлов для сборки в Arduino IDE (ядро STM32duino `Generic STM32F030C8Tx`):
* **`IMAX_B6_PRO.ino`:** Точка входа (`setup()` и `loop()`), безопасный старт силовых ключей и обязательное окно прошивки SWD `3 секунды`.
* **`config.h`:** Единый центр настроек — распиновка (включая мультиплексор `PIN_MUX_A`, `PIN_MUX_B`, `ADC_CH_MUX`), калибровочные коэффициенты АЦП (`K_B1..K_B6`, `K_VOUT`, `K_SHUNT_A`, `K_DISCH_ADC`, `K_VIN`, `PWM_DISCH_OFFSET`), лимиты 10-битного ШИМ, пороги химии (`LION_*`, `LIFE_*`), адаптивные пороги защиты входного БП (`VIN_ABS_MIN_VOLTS`, `VIN_12V_SAG_LIMIT`, `MAX_HARD_WATTS`), тепловой лимит разряда (`MAX_DISCH_WATTS`) и параметры режима БП (`PSU_*`).
* **`hal_drivers.h` / `hal_drivers.cpp`:** Прямой драйвер регистров `ADC1` (`HSI14`), разблокировка домена RTC/LSE (`PWR_CR_DBP`, `LSEON=0`, `RTC->TAFCR=0`) для `PC_13`/`PC_14`, опрос мультиплексора `readMuxAvg16()` с паузой `2 мс`, настройка ШИМ `20 кГц` (10 бит), усреднение тока шунта с паузой `15 мкс`, управление ключами и блокирующий звук `softBeep()` с флагом `buzzerEnabled`.
* **`sensors.h` / `sensors.cpp`:** Изолированный модуль измерений — опрос делителей банок (`B1..B6`), выходного напряжения (`measVout`), входного напряжения (`measVin`), каналов мультиплексора (`rawMuxY0..Y2`), расчёт тока заряда по шунту и реального тока разряда по датчику `Y2`.
* **`charger_fsm.h` / `charger_fsm.cpp`:** Конечный автомат режимов (`CHG`, `STO`, `DSC`, `BAL`), регуляторы `CC/CV` со связкой `Buck + Boost` (подключение Boost при `V_PACK + 1.5 В > V_IN`), **замкнутая стабилизация тока разряда** по датчику `Y2`, адаптивное ограничение мощности по просадке `vinMinLimit` (`12–19 В` БП), авто-режим работы сборок `1S–6S` без балансира (`useVoutAs1S`), фиксация времени завершения (`jobEndMs`), мгновенный сброс событий в телеметрию и диспетчеризация вызовов в `lab_psu` и `ir_tester`.
* **`lab_psu.h` / `lab_psu.cpp`:** Модуль лабораторного блока питания (`MODE_PSU`) с быстрым циклом стабилизации `50 мс` (`CC/CV`), связкой `Buck + Boost` (выше `10.5 В` и при `setVolts + 1.5 В > V_IN`), адаптивной защитой от просадки входа `vinMinLimit`, плавным сбросом Boost и защитой от перенапряжения (`OVP`).
* **`ir_tester.h` / `ir_tester.cpp`:** Модуль замера внутреннего сопротивления ячеек в миллиомах (`MODE_IR`) с оверсэмплингом `x128`, двухпроходным импульсным тестом нагрузки (`~3.2 Вт`) и расчётом сопротивления по **реально измеренному току импульса** через канал `Y2` (`readMuxAvg16(2) * K_DISCH_ADC`).
* **`ui_telemetry.h`:** Общий заголовочный файл подсистемы интерфейса и телеметрии.
* **`ui_buttons.cpp`:** Событийный драйвер опроса 4 кнопок с быстрым антидребезгом нажатия/отпускания `22 мс`, ускоренным длинным нажатием `STOP` (`500 мс`), 3-ступенчатым динамическим ускорением автоповтора (`140 / 75 / 45 мс`), сохранением позиции курсора `fieldIdx` при выходе из работы и переключением `V <-> A` (`START`) на лету в рабочем режиме `PSU`.
* **`ui_lcd.cpp`:** Отрисовка многоуровневого меню и рабочих экранов на дисплее `1602` без полного мерцания (`lcd.clear()` только при смене экрана), плавное мигание активных полей (`950–1300 мс / 350 мс`), показ выставляемой уставки в течение `1.5 с` при коррекции параметров `PSU` на лету, 3 рабочие страницы (`CHG/STO/DSC/BAL`, `B1..B3`, `B4..B6`) и экран результатов `IR`.
* **`telemetry.cpp`:** Компактный поток телеметрии по `SoftwareSerial` (`PA_14`, `9600 бод`) со статусными флагами `SYS`, выводом входного напряжения `Vin` и каналов мультиплексора `M1..M2`, а также выгрузкой итогового сопротивления `IR` для автономного HTML-плоттера.

## 2. Структура меню и отображение на дисплее (LCD 1602)

### 2.1. Главное меню (`SCR_MAIN`)
Прокрутка списка из 3 разделов с мигающим курсором `>...<` (`INC` — вниз, `DEC` — вверх, `START` — вход):
1. **`>WORK TO CELLS <`** — работа с аккумуляторами (`SCR_CELLS`):
   * *Верхняя строка:* `Li-Ion` / `Li-Po` / `Li-Fe` / `Li-HV` (слева) и `1S..6S` (справа).
   * *Нижняя строка:* `CHARGE` / `STORAGE` / `DISCHARGE` / `BALANCE` (слева) и ток `0.1A..5.0A` (справа; для `DISCHARGE` и `BALANCE` меню автоматически ограничивает ток до `2.0A`).
   * *Управление:* `INC`/`DEC` — изменение мигающего параметра с динамическим ускорением; короткий `STOP` — переключение мигающего поля; длинный `STOP` (`≥ 500 мс`) — возврат в Главное меню; `START` — запуск. При выходе из работы по `STOP` позиция курсора `fieldIdx` сохраняется.
2. **`> DIAGNOSTICS  <`** — диагностика и сервисные функции (`SCR_DIAGNOSTICS`, выход в Главное меню по `STOP`):
   * **`>LAB POWER SUP.<` (`SCR_PSU_SET`):** настройка напряжения `1.0..24.0V` (округление до десятых без сдвига при `10.0V`) и тока `0.1..5.0A` (переключение коротким `STOP`, выход в `DIAGNOSTICS` длинным `STOP` `500 мс`, старт по `START`).
   * **`>INTERNAL RES. <` (`SCR_IR_SET`):** выбор количества ячеек (`INTERNAL RESIST` / `CELLS: 1S  START`, мигает `1S..6S`, изменение `INC`/`DEC`, замер по `START`, возврат в `DIAGNOSTICS` по `STOP`).
3. **`>   SETTINGS   <`** — настройки прибора (`SCR_SETTINGS`):
   * **`> BUZZER: ON/OFF <`** — включение/выключение звука кнопок и сигналов по `START` (`INC`/`DEC`), возврат в Главное меню по `STOP`.

### 2.2. Формат рабочих экранов и экрана завершения (ровно 16 знакомест)
* **Экран подтверждения работы без балансира (`STATE_CONFIRM_NOBAL`, только для `2S..6S` без балансирного кабеля):**
  * *Строка 1:* `!!! WARNING !!! `
  * *Строка 2:* `NO BAL 5S START?` (повторный `START` — подтверждение запуска, `STOP` — отмена и возврат в меню).
* **Рабочий экран работы с АКБ (`runPage == 0`):**
  * *Строка 1 (асимметричная ротация `3 с` / `5 с` в цикле `8 с`):*
    * Первые `3 с`: `LIon 2S B  1.23A` — тег химии (`LIon`/`LiPo`/`LiFe`/`LiHV`), число банок, индикатор балансировки `B` и жёстко зафиксированный справа ток (`10..15`).
    * Следующие `5 с`: `DSC 13.23V 1.23A` — тег режима (`CHG`/`STO`/`DSC`/`BAL`), общее напряжение сборки (`0..9`) и неподвижный ток справа (`10..15`).
  * *Строка 2:* `00:01:23    1182` — таймер `ЧЧ:ММ:СС` слева (`0..7`), гарантированный разделитель (`8`) и ёмкость в мА·ч (до 6 цифр, выровнена строго по правому краю `16 - digits`).
* **Рабочий экран лабораторного БП (`MODE_PSU`):**
  * *Строка 1:* `PSU 12.30V 6.56A` — активное поле (`Напряжение` или `Ток`) медленно мигает (`1300 / 350 мс`) и переключается кнопкой `START`; при нажатии `INC`/`DEC` в течение `1.5 с` отображается выставляемая уставка (`setVolts` / `setAmps`), затем возвращаются реальные показания.
  * *Строка 2:* `12.4W   00:01:23` — мгновенная мощность в ваттах выровнена слева (`float left`), время `ЧЧ:ММ:СС` выровнено строго по правому краю (`float right`, позиции `8..15`).
* **Экран завершения (`STATE_DONE`):**
  * *Строка 1:* `<РЕЖИМ> OK!   (STOP)` (`CHG OK!   (STOP)`, `STO OK!   (STOP)`, `DSC OK!   (STOP)`, `BAL OK!   (STOP)` — ровно 16 символов).
  * *Строка 2:* зафиксированное итоговое время `(jobEndMs - jobStartMs)` слева и итоговая ёмкость справа.

## 4. Протокол UART-телеметрии и интеграция с веб-плоттером (`serial-plotter.html`)
* **Формат кадра (`~65 байт`, 1 раз в секунду + мгновенная отправка через `sendTelemetryNow()` при смене состояния):**
  `V:<В> I:<А> P:<ШИМ%> Q:<Ач> C1:<В> C2:<В> C3:<В> [C4..C6 при >3S] Vin:<В> M1:<raw> M2:<raw> SYS:<СТАТУС> [IR:<мОм> B1..B6]`
* **Управляющие флаги `SYS`:**
  * `IDLE` — ожидание в меню.
  * `RUN_CHG_1S..6S`, `RUN_STO_1S..6S`, `RUN_DSC_1S..6S`, `RUN_BAL_2S..6S`, `RUN_IR_1S..6S`, `RUN_PSU` — старт режима (плоттер сбрасывает график, обнуляет таймер и автоматически выставляет шкалу напряжения).
  * `STOP`, `DONE_<РЕЖИМ>`, `ERR` — остановка/завершение/авария (плоттер останавливает график, таймер и лог COM-порта).
  * `DONE_IR IR:<мОм> [B1..B6]` — выгрузка измеренного сопротивления ячейки/сборки в плоттер.

## 5. Рабочие пороги, защитные ограничители и правила разработки
1. **Пороги химии (на 1 ячейку — Заряд / Хранение / Разряд / OVP / Минимум старта):**
   * **`Li-Ion` (3.6 В):** `4.10 В / 3.75 В / 3.00 В / 4.18 В` (минимум старта `2.75 В`).
   * **`Li-Po` (3.7 В):** `4.20 В / 3.85 В / 3.10 В / 4.26 В` (минимум старта `2.75 В`).
   * **`Li-Fe` (`LiFePO4`, 3.3 В):** `3.65 В / 3.30 В / 2.60 В / 3.72 В` (минимум старта `2.30 В`).
   * **`Li-HV` (3.8 В):** `4.35 В / 3.90 В / 3.20 В / 4.42 В` (минимум старта `2.80 В`).
2. **Ограничители мощности и защита БП:**
   * Адаптивный контроль просадки входного БП: порог `vinMinLimit` вычисляется при старте как `10.6 В` (для 12 В адаптера) или `0.85 * Vin` (для 15–19 В БП), абсолютный минимум `VIN_ABS_MIN_VOLTS = 9.5 В`, безопасный потолок мощности заряда/БП `MAX_HARD_WATTS = 55.0 Вт`.
   * Разряд: `MAX_DISCH_WATTS = 7.5 Вт` с аппаратным потолком тока `MAX_DISCH_AMPS = 2.0 А` и замкнутой стабилизацией по датчику `Y2`.
3. **Авто-режим без балансира (`useVoutAs1S`):** При `C1 < 0.50 В` и попадании `V_OUT` в рабочий диапазон химии `selCells * [minStartV .. maxSafeV]` контроль ведётся по `V_OUT / selCells` (для сборок с BMS). Для `2S..6S` перед запуском обязательно выводится экран подтверждения `NO BAL <N>S START?`.
4. **Автоматическая отсечка заряда:** При достижении `vTarget - 0.01 В` и снижении тока до `10%` от эффективного тока (не ниже `0.05 А`) в течение `3 секунд` (`20` шагов по `150 мс`).
5. **Критичные правила STM32F030C8T6:** Прямые регистры `ADC1` (`HSI14`), пауза `15 мкс` при замере тока шунта, запрет `tone()`, окно `3 секунды` в `setup()` до `debugSerial.begin(9600)` для прошивки по SWD, пауза балансира `3 мс` перед замером `B1..B6`, сброс RTC/LSE для `PC_13`/`PC_14` и пауза `2 мс` после переключения канала мультиплексора `74HC4051`.
