# Паспорт проекта IMAX B6 PRO — Часть 2: Софт, интерфейс и калибровки

## 1. Модульная структура прошивки (14 файлов в папке `IMAX_B6_PRO`)
Проект организован в виде 14 раздельных файлов для сборки в Arduino IDE (ядро STM32duino `Generic STM32F030C8Tx`):
* **`IMAX_B6_PRO.ino`:** Точка входа (`setup()` и `loop()`), безопасный старт силовых ключей и обязательное окно прошивки SWD `3 секунды`.
* **`config.h`:** Единый центр настроек — распиновка (включая мультиплексор `PIN_MUX_A`, `PIN_MUX_B`, `ADC_CH_MUX`), калибровочные коэффициенты АЦП (`K_B1..K_B6`, `K_VOUT`, `K_SHUNT_A`, `K_DISCH_CALIB`, `K_DISCH_ADC`, `K_VIN`, `PWM_DISCH_OFFSET`), лимиты 10-битного ШИМ, пороги химии (`LION_*`, `LIFE_*`), пороги защиты по мощности (`MAX_OUTPUT_WATTS`, `MAX_DISCH_WATTS`) и параметры режима БП (`PSU_*`).
* **`hal_drivers.h` / `hal_drivers.cpp`:** Прямой драйвер регистров `ADC1` (`HSI14`), разблокировка домена RTC/LSE (`PWR_CR_DBP`, `LSEON=0`, `RTC->TAFCR=0`) для `PC_13`/`PC_14`, опрос мультиплексора `readMuxAvg16()`, настройка ШИМ `20 кГц` (10 бит), усреднение тока шунта с паузой `15 мкс`, управление ключами и блокирующий звук `softBeep()` с флагом `buzzerEnabled`.
* **`sensors.h` / `sensors.cpp`:** Изолированный модуль измерений — опрос делителей банок (`B1..B6`), выходного напряжения (`measVout`), каналов мультиплексора (`rawMuxY0..Y2`), расчёт тока заряда по шунту и тока разряда.
* **`charger_fsm.h` / `charger_fsm.cpp`:** Конечный автомат режимов (`CHG`, `STO`, `DSC`, `BAL`), регуляторы `CC/CV` со связкой `Buck + Boost`, авто-режим работы сборок `1S–6S` без балансира (`useVoutAs1S`), ограничители мощности, фиксация времени завершения (`jobEndMs`), мгновенный сброс событий в телеметрию и диспетчеризация вызовов в `lab_psu` и `ir_tester`.
* **`lab_psu.h` / `lab_psu.cpp`:** Модуль лабораторного блока питания (`MODE_PSU`) с быстрым циклом стабилизации `50 мс` (`CC/CV`), связкой `Buck + Boost` (выше `10.5 В`), плавным сбросом Boost при снижении уставки и защитой от перенапряжения (`OVP`).
* **`ir_tester.h` / `ir_tester.cpp`:** Модуль замера внутреннего сопротивления ячеек в миллиомах (`MODE_IR`) с оверсэмплингом `x128` и двухпроходным импульсным тестом нагрузки (`~3.2 Вт`).
* **`ui_telemetry.h`:** Общий заголовочный файл подсистемы интерфейса и телеметрии.
* **`ui_buttons.cpp`:** Событийный драйвер опроса 4 кнопок с фильтром минимального нажатия `60 мс`, блокировкой до полного отпускания (`60 мс` — защита от проскоков меню), автоповтором `220 мс` для регулировки параметров и разделением короткого/длинного (`800 мс`) нажатия `STOP`.
* **`ui_lcd.cpp`:** Отрисовка многоуровневого меню и рабочих экранов на дисплее `1602` без полного мерцания (`lcd.clear()` только при смене экрана), асимметричное мигание активного поля (`750 мс / 450 мс`), 3 рабочие страницы (`CHG/STO/DSC/BAL`, `B1..B3`, `B4..B6`) и экран результатов `IR`.
* **`telemetry.cpp`:** Компактный поток телеметрии по `SoftwareSerial` (`PA_14`, `9600 бод`) со статусными флагами `SYS`, диагностикой каналов мультиплексора `M0..M2` и выгрузкой итогового сопротивления `IR` для автономного HTML-плоттера.

## 2. Структура меню и отображение на дисплее (LCD 1602)

### 2.1. Главное меню (`SCR_MAIN`)
Прокрутка списка из 3 разделов с курсором `>...<` (`INC` — вниз, `DEC` — вверх, `START` — вход):
1. **`>WORK TO CELLS <`** — работа с аккумуляторами (`SCR_CELLS`):
   * *Верхняя строка:* `Li-Ion` / `Li-Fe` (слева) и `1S..6S` (справа).
   * *Нижняя строка:* `CHARGE` / `STORAGE` / `DISCHARGE` / `BALANCE` (слева) и ток `0.1A..5.0A` (справа).
   * *Управление:* `INC`/`DEC` — изменение мигающего параметра; короткий `STOP` — переключение мигающего поля; длинный `STOP` (`≥ 800 мс`) — возврат в Главное меню; `START` — запуск.
2. **`>   SERVICES   <`** — сервисные функции (`SCR_SERVICES`, выход в Главное меню по `STOP`):
   * **`>LAB POWER SUP.<` (`SCR_PSU_SET`):** настройка напряжения `1.0..24.0V` и тока `0.1..5.0A` (мигающее поле, переключение коротким `STOP`, выход в `SERVICES` длинным `STOP`, старт по `START`). Во время работы `INC`/`DEC` меняют напряжение на лету, `STOP` останавливает и возвращает в `SCR_PSU_SET`.
   * **`>INTERNAL RES. <` (`SCR_IR_SET`):** выбор количества ячеек `CELLS: >1S..6S<` (`INC`/`DEC`), замер по `START`, возврат в `SERVICES` по `STOP`.
3. **`>   SETTINGS   <`** — настройки прибора (`SCR_SETTINGS`):
   * **`> BUZZER: ON/OFF <`** — включение/выключение звука кнопок и сигналов по `START` (`INC`/`DEC`), возврат в Главное меню по `STOP`.

### 2.2. Формат рабочего экрана и экрана завершения (ровно 16 знакомест)
* **Рабочий экран (`runPage == 0`):**
  * *Строка 1:* `CHG 1S  B  2.23A` — режим и число банок слева, индикатор балансировки `B` по центру, текущий ток с буквой `A` в позиции `15` справа.
  * *Строка 2:* `00:01:23    1182` — таймер `ЧЧ:ММ:СС` слева (`0..7`), гарантированный разделитель (`8`) и ёмкость в мА·ч (до 6 цифр, выровнена строго по правому краю `16 - digits`).
* **Экран завершения (`STATE_DONE`):**
  * *Строка 1:* `COMPLETE! (STOP)`
  * *Строка 2:* зафиксированное итоговое время `(jobEndMs - jobStartMs)` слева и итоговая ёмкость справа.

## 4. Протокол UART-телеметрии и интеграция с веб-плоттером (`plotter.html`)
* **Формат кадра (`~65 байт`, 1 раз в секунду + мгновенная отправка через `sendTelemetryNow()` при смене состояния):**
  `V:<В> I:<А> P:<ШИМ%> Q:<Ач> C1:<В> C2:<В> C3:<В> [C4..C6 при >3S] M0:<raw> M1:<raw> M2:<raw> SYS:<СТАТУС> [IR:<мОм> B1..B6]`
* **Управляющие флаги `SYS`:**
  * `IDLE` — ожидание в меню.
  * `RUN_CHG_1S..6S`, `RUN_STO_1S..6S`, `RUN_DSC_1S..6S`, `RUN_BAL_2S..6S`, `RUN_IR_1S..6S`, `RUN_PSU` — старт режима (плоттер сбрасывает график, обнуляет таймер и автоматически выставляет шкалу напряжения).
  * `STOP`, `DONE_<РЕЖИМ>`, `ERR` — остановка/завершение/авария (плоттер останавливает график, таймер и лог COM-порта).
  * `DONE_IR IR:<мОм> [B1..B6]` — выгрузка измеренного сопротивления ячейки/сборки в плоттер.

## 5. Рабочие пороги, защитные ограничители и правила разработки
1. **Пороги химии (на 1 ячейку):** `Li-Ion` — `4.20 В / 3.80 В / 3.10 В / 4.26 В`; `LiFePO4` — `3.65 В / 3.30 В / 2.60 В / 3.72 В`.
2. **Ограничители мощности:** Заряд `MAX_OUTPUT_WATTS = 19.5 Вт` (защита входного БП `12 В / 2 А`); Разряд `MAX_DISCH_WATTS = 5.5 Вт` (защита транзисторов `IRFZ44N` и `D880-Y`).
3. **Авто-режим без балансира (`useVoutAs1S`):** При `C1 < 0.50 В` и попадании `V_OUT` в диапазон `selCells * 2.20..4.35 В` контроль ведётся по `V_OUT / selCells` (для сборок с BMS).
4. **Автоматическая отсечка заряда:** При достижении `vTarget - 0.01 В` и снижении тока до `10%` от эффективного тока (не ниже `0.05 А`) в течение `3 секунд` (`20` шагов по `150 мс`).
5. **Критичные правила STM32F030C8T6:** Прямые регистры `ADC1` (`HSI14`), пауза `15 мкс` при замере тока шунта, запрет `tone()`, окно `3 секунды` в `setup()` до `debugSerial.begin(9600)` для прошивки по SWD, пауза балансира `3 мс` перед замером `B1..B6`, сброс RTC/LSE для `PC_13`/`PC_14` и пауза `2 мс` после переключения канала мультиплексора `74HC4051`.
