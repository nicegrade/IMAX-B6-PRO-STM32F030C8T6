# Паспорт проекта IMAX B6 PRO — Часть 1: Аппаратная платформа и полная трассировка платы

## 1. Аппаратная идентификация платы
* **Устройство:** Модифицированный клон балансирного зарядного устройства IMAX B6 (ревизия без усилителя шунта `LM358`, с 8-канальным аналоговым мультиплексором `74HC4051`).
* **Микроконтроллер (`U2`):** `STM32F030C8T6` (ядро ARM Cortex-M0, `48 МГц`, Flash `64 КБ`, RAM `8 КБ`, корпус `LQFP48`, точка-ключ в левом верхнем углу).
* **Аналоговый мультиплексор (`U4`):** `74HC4051` (корпус `SOIC-16`, ключ в правом верхнем углу; правый ряд сверху вниз `1..8`, левый ряд снизу вверх `9..16`).
* **Опорное напряжение АЦП (`VREF` / `VDDA`):** `3.30 В` (стабилизатор `3.3 В` на плате).
* **Питание устройства и стабилизация логики:**
  * Внешний источник постоянного тока `11.0 .. 19.5 В` (поддерживаются стандартные адаптеры `12 В / 2 А` и ноутбучные БП `19 В` с автоматической адаптацией порога просадки).
  * Линейный стабилизатор **`D880-Y`** (`TO-220`, возле входного разъёма питания, коллектор подключён к входному `+V_IN`) формирует шину **`+5 В`** для подсветки дисплея LCD 1602 и питания стабилизатора `3.3 В` микроконтроллера.
* **Индикация и управление:**
  * Символьный ЖК-дисплей `1602` (16 символов × 2 строки, контроллер HD44780, 4-битная шина данных).
  * 4 тактовые кнопки (`STOP`, `DEC`, `INC`, `START`) с подтяжкой к `+3.3 В` (`INPUT_PULLUP`, активный уровень `LOW`).
  * Пассивный пьезоизлучатель (`PB_4`), требующий программной генерации меандра (`softBeep()`).

## 3. Измерительные цепи АЦП (`ADC1`, 12 бит: `0..4095`)
Основные силовые и балансирные каналы заведены напрямую на входы `PA_0..PA_7` микроконтроллера без внешнего ОУ `LM358`, а вспомогательные датчики коммутируются через `U4` (`74HC4051`) на вход `PB_1` (`ADC1_CH9`):

| Ножка U2 | Порт STM32 | Канал ADC1 | Измеряемый узел | Аппаратная специфика и калибровочный коэффициент |
| :---: | :--- | :---: | :--- | :--- |
| **10** | `PA_0` | `CH0` | Токовый шунт заряда / БП (прямой съём) | Программная калибровка нуля (`shuntZero`) при открытом `V21` до запуска ШИМ; усреднение x64 с шагом `15 мкс` (`K_SHUNT_A = 0.075f`) |
| **11** | `PA_1` | `CH1` | Делитель балансира `B1` (`Cell 1`) | Коэффициент делителя `1.383` (`K_B1 = (3.30 / 4095) * 1.383`) |
| **12** | `PA_2` | `CH2` | Делитель балансира `B2` (`Cell 1+2`) | Коэффициент делителя `2.752` (`K_B2 = (3.30 / 4095) * 2.752`) |
| **13** | `PA_3` | `CH3` | Делитель балансира `B3` (`Cell 1..3`) | Коэффициент делителя `4.191` (`K_B3 = (3.30 / 4095) * 4.191`) |

| **15** | `PA_5` | `CH5` | Делитель балансира `B5` (`Cell 1..5`) | Коэффициент делителя `6.802` (`K_B5 = (3.30 / 4095) * 6.802`) |

| **3** | `Z` (Common Out) | **Ножка 19 `U2` (`PB_1`, `ADC1_CH9`)** | Общий аналоговый выход на АЦП микроконтроллера |

| **16** | `VCC` | **`+3.3 В` / `+5 В`** | Питание логики мультиплексора |

### Б. Блок-схемы прохождения сигналов по основным узлам

```text

[STM32 Pin 29: PA_8] ──► [R22 / RC] ──► [Драйвер V8/V9] ──► [Gate IRFZ44N]
[Клемма DC+] ─────────────────────────────────────────────► [Drain IRFZ44N]
[Шунт разряда / GND] ◄──────────────────────────────────── [Source IRFZ44N]
       │
       └──► [Узел V5 / C3] ──► [C6 / R18] ───────────────► [U4 Pin 15 (Y2)]

2. ВЫХОДНОЙ ЗАЩИТНЫЙ КЛЮЧ АКБ:
[STM32 Pin 26: PB_13] ──► [R74 / V24] ──► [Gate (Pin 4) V21 AO4468]
[Клемма DC−] ───────────────────────────► [Drain (Pins 5..8)]
[Токовый шунт заряда / GND] ◄────────── [Source (Pins 1..3)]

3. АНАЛОГОВЫЙ МУЛЬТИПЛЕКСОР U4 (74HC4051):
[Вход +12..19 В] ──► [Делитель R42] ─────────► [Y0 (Pin 13)] ──┐
[Разъём CN1]     ──► [R91 / R92 / C18] ──────► [Y1 (Pin 14)] ──┼──► [Z (Pin 3)] ──► [STM32 Pin 19: PB_1 / CH9]
[Узел V5 / C3]   ──► [C6 / R18] ─────────────► [Y2 (Pin 15)] ──┘         ▲
                                                                          │
                                 [STM32 Pin 2 (PC_13 = A), Pin 3 (PC_14 = B), Pins 6..9 U4 = GND]

4. СТАБИЛИЗАТОР ПИТАНИЯ ПЛАТЫ:
[Вход +12..19 В] ──► [Collector D880-Y] ──► [Emitter (+5 В: LCD)] ──► [LDO 3.3 В] ──► [VDD / VDDA STM32]
```

## 5. Тепловые и электрические ограничения силовой части
1. **Тепловой режим разрядного транзистора (`IRFZ44N`):**
   * Полевой транзистор `IRFZ44N` работает в линейном режиме (`Drain = DC+`, `Source = GND`) и прикручен к алюминиевому корпусу через термопрокладку без активного обдува. Рассеиваемая мощность при разряде ограничена порогом `MAX_DISCH_WATTS = 7.5 Вт` с аппаратным потолком тока `MAX_DISCH_AMPS = 2.0 А` и замкнутой стабилизацией по каналу `Y2` (на `1S` ток достигает `1.85–2.00 А`, на `5S` — `0.36–0.48 А`, нагрев корпуса в точке крепежа ключа не превышает `47–53 °C`).
   * В режиме замера внутреннего сопротивления (`IR`) на `IRFZ44N` подаётся кратковременный импульс нагрузки мощностью не более `3.2 Вт` длительностью `450 мс` (2 прохода) с измерением реального тока импульса через `Y2`.
2. **Адаптивная защита входного БП (`VIN_12V_SAG_LIMIT = 10.6 В`, `MAX_HARD_WATTS = 55.0 Вт`):**
   * При запуске измеряется холостое входное напряжение `measVin`. Для адаптеров `12 В` (`measVin < 14.5 В`) порог просадки фиксируется на `10.6 В`, для БП `15–19 В` (`measVin >= 14.5 В`) — на уровне `85%` от `measVin`. Максимальная мощность заряда/БП ограничена безопасным для дросселя Buck и диода `MBR1560C` потолком `55.0 Вт`. При достижении порога регулятор плавно снижает скважность ШИМ, удерживая максимальную безопасную мощность без ухода адаптера в защиту.
3. **Подключение программатора ST-Link V2 и UART-телеметрии:**
   * В течение первых 3 секунд после подачи питания `PA_14` остаётся в режиме `SWD` для перепрошивки. При подключении USB-UART переходника для снятия графиков линию `SWCLK` от ST-Link необходимо отключать.
